## 2. 认证

除 `/api/auth/login` 和 Swagger 外，所有 `/api/**` 都需要请求头 `Authorization: Bearer <token>`。助手服务（8093 / 8094）校验的是同一个 JWT（密钥 `JWT_SECRET` 两边一致）。

```bash
# 登录并取 token（演示账号密码均为 Demo@2026）
TOKEN=$(curl -s -X POST http://localhost:8080/api/auth/login \
  -H 'Content-Type: application/json' \
  -d '{"username":"admin","password":"Demo@2026"}' | python3 -c 'import sys,json;print(json.load(sys.stdin)["token"])')

# 调后端
curl -H "Authorization: Bearer $TOKEN" http://localhost:8080/api/auth/me
# 调助手
curl -H "Authorization: Bearer $TOKEN" http://localhost:8093/sessions
```

| 账号 | 角色 | 说明 |
|---|---|---|
| admin | ADMIN | 全部功能，含审计日志 |
| cfo | MANAGEMENT | 只读看板 / 应收应付 / 成本 |
| fin01 | FINANCE | 开票、收付款、费用审批 |
| sales01 | SALES | 销售订单、客户（看不到成本和毛利） |
| buyer01 | PURCHASE | 采购、供应商 |
| wh01 | WAREHOUSE | 发货、到货、库存调整 |
| prod01 | PRODUCTION | 工单、报工、BOM |
| qa01 | QUALITY | 来料检验、客诉 8D |
| eng01 / eng02 | ENGINEER | ECN、技术文档、NPI |

接口表里的“权限”列：空表示登录即可；有值表示 `@PreAuthorize` 限定的角色。浏览器不能直接带 Bearer 头，GET 接口建议用 Swagger UI 或 curl 访问。

## 6. 常见访问问题

- 端口冲突：5180、8080、3307、8093、8094，以及助手基础设施的 3001、3003、9010 等。启动前可用 `lsof -iTCP:<端口> -sTCP:LISTEN -n -P` 检查。
- 前端 Docker 里的 `/copilot-api`、`/kbase-api` 代理到 `host.docker.internal`，所以 Python 服务要在宿主机上运行，不是容器。
- 助手需要在 MySQL 中有 `assistant`、`copilot_ro` 账号，初始化脚本在 `assistant/mysql-init/`；已有数据卷时需手动执行一次。
