## 三、背后怎么做的（讲解用）

```
松下官网 2D 外形图（DXF，Scrapling 抓取，5,157 张）
→ ezdxf 读几何 → 去掉中心线，按包围盒连通把一张图切成 7~10 个视图
→ 侧视图：轴端水平线间距 = 轴径；合并断开的竖线找法兰安装面 → 轴伸、机身长
→ 前视图：止口 = 小于法兰的最大同心圆；安装孔 = 四个象限对称、等大等距的圆 → 节圆
→ 生成图纸卡片（Markdown + 渲染图）+ 汇总表（分组、对比的差值由程序算好）
→ 知识库入库流水线（切片、向量化、三路召回）
→ 问答：检索 → 生成 → 引用校验
```

讲点：
1. **原图没有尺寸标注**：松下这批图只有外形轮廓，尺寸是从几何量出来的，不是读文字。
2. **为什么汇总表里要写好差值**：知识库的引用校验不允许回答里出现资料里没有的数字。第一次测「差多少」时，模型自己算出的 36.5 被当成来源不明的数字拦下了。所以改成由程序把差值算好写进资料，模型只负责复述。
3. **量不准的就写「未识别」**：100W 的 40 小法兰安装孔没识别出来，卡片里如实写，问答也如实答。

## 四、要注意的地方（被问到要如实说）

- 数值是**几何测量值**，和松下样本上的标注值可能有零点几毫米的出入，比如 100 法兰量出来是 100.6（视图宽度包含了凸出的部分）。正式数值以松下样本为准；样本 PDF 要在官网填表单才能下载，还没下。
- 抽取规则只在这 13 张图上调过，没有在全部 5,157 张上做准确率评测；下一步是拿样本里的尺寸表当标准答案来测。
- 资料版权归松下，只用于内部演示。
