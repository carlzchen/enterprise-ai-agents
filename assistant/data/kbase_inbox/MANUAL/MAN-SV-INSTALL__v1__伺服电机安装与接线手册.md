# 伺服电机安装与接线手册

## 1 安装环境

电机应安装在通风良好、无腐蚀性气体、无导电粉尘的场所，环境温度 0 到 40 摄氏度，相对湿度不超过 90%（无凝露），海拔不超过 1000 米。

## 2 机械安装

电机与负载连接时必须使用联轴器对中，同轴度误差不大于 0.03 毫米。严禁用锤子敲击电机轴端，否则会损坏编码器。
安装螺栓按对角顺序分两次拧紧。皮带传动时，径向载荷不得超过产品规格书的允许值。

## 3 接线

动力线 U、V、W 必须与驱动器对应端子一一连接，相序接错会导致电机飞车。编码器线缆使用屏蔽双绞线，屏蔽层在驱动器侧单端接地，长度不超过 20 米。
电机外壳接地端子必须可靠接地，接地电阻不大于 0.1 欧。
